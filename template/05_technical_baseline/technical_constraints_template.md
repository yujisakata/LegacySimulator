# **技術制約書 (Technical Constraints)**

**文書ID:** DOC-TEC-001  
**対象バージョン:** V1 (1980年代ベースライン)  

---

## **1. 実行環境・言語制約**
| 項目 | 採用技術 | 制限ルール・制約 |
| :--- | :--- | :--- |
| **言語** | Java 21 | ※ただしJava 1.4相当の文法のみ使用可（Generics/Stream禁止） |
| **フレームワーク** | なし | Spring Boot等のDIコンテナ使用禁止 |
| **永続化** | ファイルI/Oのみ | ORM/RDBの使用禁止（フラットファイルのみ） |
| **UI** | コンソール (標準入出力) | プレゼンテーション層とロジックの密結合を意図的許容 |

## **2. 設計・改修ルール**
* **リファクタリング:** 原則禁止（既存コードへの影響を最小限にするパッチ改修を優先）
