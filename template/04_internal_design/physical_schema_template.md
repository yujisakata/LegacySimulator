# **物理DB設計書 (DDL仕様)**

**文書ID:** DOC-INT-004  

---

## **1. テーブル定義: `T_APPLICATION`**
```sql
CREATE TABLE T_APPLICATION (
    APP_NO VARCHAR(10) NOT NULL,
    APPLY_DATE DATE NOT NULL,
    STATUS VARCHAR(2) NOT NULL,
    INSURED_NAME VARCHAR(50),
    CONSTRAINT PK_T_APPLICATION PRIMARY KEY (APP_NO)
);
```

## **2. インデックス定義**
```sql
CREATE INDEX IDX_APP_STATUS ON T_APPLICATION(STATUS, APPLY_DATE);
```
