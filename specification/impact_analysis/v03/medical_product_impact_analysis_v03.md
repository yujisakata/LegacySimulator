# 医療保険・がん保険 影響分析書 (V3)

**文書ID:** DOC-IMP-V3-001  
**結論:** 既存商品を変更せず、医療系商品プログラムとジョブステップを追加する。

## 1. 追加・変更対象

| 対象 | 対応 |
| :--- | :--- |
| MDENTRY | NBENTRYを複製し、MI・CI入力へ変更する。 |
| MDASSESS | NBASSESSの共通事務処理を複製し、商品固有条件へ置換する。 |
| MDAPPL・MDRESULT | 120/80文字の同一物理位置を商品別名称で定義する。 |
| MDJOB01 | 商品別ロードモジュールを既存ジョブネットへ追加する。 |
| V1・V2ソース | 変更しない。 |
| 原本設計・運用手順 | 変更せず、V3別冊とリリース記録で補う。 |

## 2. 複製後に実行対象から外す条件

- WLだけを許可する商品点検
- 死亡保険金額の上限と決裁境界
- V2特約入力・査定・結果

不備期限、三要件、取下げ、Gregorian日付点検、件数管理、ファイル異常処理は複製して継承する。

## 3. 互換性

61～68桁は物理形式を維持し、商品コードMI・CIに応じて保障額の意味を変える。75～120桁はMI・CIでは空白必須とする。結果1～40桁はV1と同一形式、41～80桁は空白とする。

## 4. リスク

| リスク | 対応 |
| :--- | :--- |
| 共通段落が複数商品へ複製される | ナレッジグラフへ重複関係を登録する。 |
| 原本・V2追補・V3別冊の読順が不明確 | 要件索引と設計別冊に優先順を記載する。 |
| 既存商品の試験範囲が限定される | 1990年証拠と2026年自動回帰を区別する。 |
| 保障額の意味が商品で異なる | 商品コードと61～68桁を必ず組で解釈する。 |
