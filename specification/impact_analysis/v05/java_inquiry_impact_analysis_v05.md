# V5 変更影響分析

対象Version: V4→V5<br>
想定読者: 開発・検証・講師

V4のソース/COPY/設計を変更しない。照会用複製への新たな読取り依存を追加する。

| 変更要求 | 直接対象 | 同時確認が必要なもの |
|---|---|---|
| 照会項目追加 | Q5変換、Record、SQL、DAO、Servlet | V4項目の出典・意味、未設定の扱い、全100文字 |
| V4レコード位置変更 | SnapshotExportJob | COPYとQ5変換表、商品別結合試験 |
| 主契約コード追加 | Converterと表示表 | COBOL結果、DB制約、業務文言 |
| 商品追加 | Exportの系統判定、Converter、DB、表示ラベル | 保障額の意味、単位、既存3商品への影響 |
| 同期時刻変更 | 運用手順、取得基準日 | 利用者説明、翌朝に前回値が出る条件 |
| 再告知規則変更 | まずV4側で影響分析 | V5は結果転記を維持できるか、制度欄の表示の確認 |

直接CALLしないCOBOLとJavaにも、固定長の位置・コード意味による変更関係が発生した。単一言語の呼出図ではこの影響を把握できない。

原簿側の再起票運用をJavaの新規受付機能として実装することは対象外。未知の業務判断は[未確認事項](../../../knowledge/examples/v05_inquiry_knowledge_distribution.md)として保持する。
