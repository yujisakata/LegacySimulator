# V1回帰テスト用ゴールデンデータ仕様書

**文書ID:** DOC-VAL-V1-002  
**データセットID:** GOLDEN-V1-NEWBUS-001  
**対象Version:** V1

## 1. 目的

V1の業務規則と固定長インターフェースを、将来のVersionおよびV10の現新比較で再現するための基準データとする。正常系だけでなく、決裁境界、年齢・金額境界、不備期限、取下げ、未充足、入力エラーを含む。

## 2. 構成

| 資産 | 用途 | 管理上の位置づけ |
| :--- | :--- | :--- |
| `test/v01/cases/assessment_cases.csv` | 人がレビューする入力と期待値 | ケース定義の正本 |
| 実行時`APPLICATION.DAT` | 120文字のCOBOL入力 | CSVから決定的に生成 |
| `test/v01/expected/ASSESSMENT.DAT` | 80文字の期待結果 | 承認済みゴールデン出力 |
| `test/v01/scripts/run-tests.ps1` | 生成・桁数検証・完全一致比較 | 2026年追加の検証補助 |

## 3. 比較条件

- レコード件数が19件で一致すること。
- 入力は各120文字、出力は各80文字であること。
- 申込番号順ではなく入力順で比較すること。
- 予約領域の空白を含め、大文字・小文字を区別した完全一致とすること。
- 改行コードはレコード区切りとして扱い、業務データの比較対象外とすること。

## 4. 変更規則

V1の業務仕様に訂正がない限り、既存期待値を変更しない。処理系対応やスクリプト修正で結果差が出た場合は、業務ルール、設計、COBOL、期待値の順で根拠を確認する。V2以降の変更要求はV1データを上書きせず、Version別データセットとして追加する。
