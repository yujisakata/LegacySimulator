# 新契約査定システム 技術基準書 (V3)

**文書ID:** DOC-TEC-V3-001  
**参照:** technical_constraints/version_profiles.yml のV3

## 1. 技術基準

| 項目 | V3基準 |
| :--- | :--- |
| 言語 | 固定形式COBOL、JCL相当 |
| 構成 | 商品別に複製したオンライン・バッチ |
| データ | 商品別再定義を含む固定長ファイル |
| 配布 | 商品別ロードモジュールを個別配布 |
| ジョブ | 商品別ステップを単一ジョブネットへ追加 |
| 試験 | 新商品中心、既存商品は代表確認 |

## 2. 制約

商品共通基盤の新設と、全面回帰を前提とした共通化は行わない。コピー元とコピー先の共通判定を自動同期する仕組みは導入しない。

## 3. 教材検証

1990年当時の成果物と、2026年に追加したGnuCOBOL・PowerShell自動検証を区別する。ソースは72桁以内とし、日本語コメントを含むUTF-8教材としてGnuCOBOL 3.2.0で検証する。
