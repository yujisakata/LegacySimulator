# V4技術基準

対象Version: V4（1995年相当）<br>
想定読者: 開発・教材検証担当

[V4技術プロファイル](../../../technical_constraints/version_profiles.yml)と[移行規則](../../../technical_constraints/transition_rules.yml)に従う。

COBOL固定形式、JCL相当、文字端末、商品系統別の受付・査定、固定長の契約ファイルを継続する。NB系統はV2、MD系統はV3を継承し、COPYとロードモジュールを個別配布する。共通化・旧段落削除・システム日時による制度選択は行わない。

申込120文字・結果80文字を維持する。制度日前後のレコードを同一商品系統ジョブで処理する。制度日マスタは施行前に配布し、業務基準日との比較で適用する。入力、結果、使用マスタを同一実行単位で保管する。マスタ異常時は業務処理開始前に停止する。

## 2026年の実行環境

GnuCOBOL 3.2.0、PowerShell、Python 3の標準ライブラリで検証する。日本語コメントはUTF-8、業務データはASCII数字・英字・空白。固定長ファイルは改行区切りで再現し、COB_LS_FIXED=TRUEを必須とする。改行は120/80文字に含めない。バッチ読込では実長を別途点検する。

JCLは当時の処理順の説明資産であり、この環境で実行するのは[PowerShellジョブ](../../../implementation/v04/jcl/run-job-v04.ps1)。実メインフレームのロード、文字端末基盤、契約原簿管理機能そのものは再現対象外。
