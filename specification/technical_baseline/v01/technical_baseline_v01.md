# 新契約査定システム 技術基準書 (V1)

**文書ID:** DOC-TEC-V1-001  
**対象Version:** V1（1980年）  
**参照:** [V1技術プロファイル](../../../technical_constraints/version_profiles.yml)

## 1. 技術基準

| 項目 | V1基準 |
| :--- | :--- |
| 言語 | ANSI COBOL相当、JCL相当 |
| オンライン | 文字端末、画面単位の手続き型プログラム |
| バッチ | 行順次固定長ファイルの逐次処理 |
| 永続化 | ファイルのみ。RDB、ORMを使用しない |
| 連携 | ファイル受渡し、紙帳票 |
| 文字 | 実機はEBCDIC相当。教材はASCII互換の英数字コードだけで再現 |
| ビルド | COBOLコンパイル、リンク、ロードモジュール配布 |
| 試験 | 代表データ、境界値、ジョブ結合、結果ファイル目視確認 |

## 2. 教材上の可搬性

COBOLソースはGnuCOBOLで検証可能な固定形式を目標とする。ただし、GnuCOBOL、PowerShell、自動比較スクリプトは2026年の教材検証環境であり、1980年当時の本番構成には含めない。当時の成果物と後世に追加した検証資産はファイル配置と文書で区別する。

## 4. 変更管理

V1はベースラインであるため、業務仕様、設計、ソース、試験期待値を同期して変更する。値の変更には業務ルール仕様書の改訂を先行させ、トレーサビリティ表の全対応先を確認する。
