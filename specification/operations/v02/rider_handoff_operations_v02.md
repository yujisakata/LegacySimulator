# 特約結果受渡し 運用追補 (V2)

**文書ID:** DOC-OPS-V2-001  
**対象:** 新契約査定から証券発行・通知作成への日次受渡し

## 1. 責任分界

新契約部はASSESSMENT.DATの作成、80文字長、入出力件数および特約結果項目の妥当性に責任を持つ。証券発行部は41～64桁の取込み、結果Aの特約記載、P/D/R/X/Eの通知・保留処理に責任を持つ。

## 2. 日次確認

1. NBJOB01の戻り値が0であることを確認する。
2. NBASSESSの入力件数と出力件数が一致することを確認する。
3. データエラー件数がある場合、主契約08または特約Eを一覧化する。
4. 証券発行部へファイル件数と処理基準日を通知する。

## 3. 移行前確認

証券発行部が従来の41～80桁を予約領域として一括判定していないことを、対象ジョブ一覧と代表ファイルで共同確認する。この確認結果は本番移行判定記録へ添付する。
