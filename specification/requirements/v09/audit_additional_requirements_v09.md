# V9 追加要件定義書 — 横断監査

| ID | 要件 | 受入条件 |
|---|---|---|
| V9-FR-001 | 入力、理由、操作者、時刻、取引キーを記録する | 5項目が監査イベントに存在する |
| V9-FR-002 | 異なる時刻オフセットをUTCへ正規化する | 同一瞬間のログが同じUTC時刻となる |
| V9-FR-003 | 旧Spring/Boot/COBOLを取引キーで相関する | 同じ取引キーで経路を検索できる |
| V9-FR-004 | 本人確認を独立リリース可能にする | Bootアダプタが共有DB更新後にメッセージを発行する |
| V9-NFR-001 | 元時刻とオフセットを保持する | 監査イベントから発生元表記を再現できる |
