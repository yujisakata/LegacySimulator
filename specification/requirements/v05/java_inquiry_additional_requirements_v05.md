# V5 追加要件定義書 — Java契約照会

| ID | 要件 | 受入条件 |
|---|---|---|
| V5-FR-001 | 固定長スナップショットを照会レコードへ変換する | 契約番号、状態、金額、基準日を項目定義どおり取得できる |
| V5-FR-002 | 契約番号で参照専用照会を行う | 取得処理だけを公開し更新処理を公開しない |
| V5-FR-003 | データ基準日を応答へ含める | 前夜時点であることを利用者が判別できる |
| V5-NFR-001 | 契約原簿へJavaから更新しない | Web照会はSELECTだけを使用し、夜間取込は照会用複製DBだけを入れ替える |
| V5-NFR-002 | 空白・ゼロ・NULLを区別する | 空白状態はnull、ゼロ金額は数値0、空白金額はnullとなる |
| V5-OPS-001 | 2週間の引継ぎに必要な運用情報を残す | 主要ジョブ、再実行、責任分界を運用資料で確認できる |
