# V10 要件定義書 — 知識復元

| ID | 要件 | 受入条件 |
|---|---|---|
| V10-FR-001 | V1～V9の要件・設計・実装・テストを証拠として登録する | 各エッジにVersionと根拠種別がある |
| V10-FR-002 | 証拠種別から確信度を算出する | 要件0.2、設計0.2、コード0.3、テスト0.3で再計算できる |
| V10-FR-003 | 反証があるエッジを識別する | `contradicted=true` の確信度を最大0.5とし要レビューにする |
| V10-FR-004 | ゴールデンケースで現行動作を再現する | 入力、期待出力、根拠Versionを追跡できる |
| V10-NFR-001 | AI推定を未審査で確定しない | レビュー状態がPENDING/APPROVEDとして出力される |
| V10-NFR-002 | 既存形式を保持する | 意味マッピングを別成果物として生成する |
