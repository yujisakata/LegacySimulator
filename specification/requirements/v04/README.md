# V4要件・成果物の入口

対象Version: V4<br>
想定読者: 開発・検証・教材管理者

1. [最終要件定義](regulatory_additional_requirements_v04.md): 当初要求と補正要求、今回確定した教材条件。
2. [業務ルール](../../business_specification/v04/regulatory_business_rules_delta_v04.md)と[判断記録](../../business_specification/v04/regulatory_design_deliberation_v04.md)。
3. [技術基準](../../technical_baseline/v04/technical_baseline_v04.md)、[外部設計](../../external_design/v04/regulatory_effective_date_design_v04.md)、[内部設計](../../internal_design/v04/regulatory_cobol_design_v04.md)。設計追補本文は施行前の版。
4. [補正指示](../../validation_history/v04/incident_patch_note_v04.md)と[最終実装](../../../implementation/v04/README.md)。
5. [検証仕様](../../validation_history/v04/test_specification_v04.md)、[要件対応表](../../validation_history/v04/traceability_matrix_v04.md)、[実行結果](../../validation_history/v04/test_result_v04.md)。
6. [V3→V4分析](../../evolution_analysis/v04_transition_analysis.md)、[知識の分散](../../../knowledge/examples/v04_regulatory_knowledge_distribution.md)。最後の2点は講師向け。
7. [運用追補](../../operations/v04/regulatory_operations_v04.md): マスタ配布・証跡保管・補正の改訂履歴。

演習ではこの入口と統合要件・対応表を最初から渡さず、[講師向け提示順](../../../knowledge/examples/v04_regulatory_knowledge_distribution.md)に従って情報を段階的に開示する。
