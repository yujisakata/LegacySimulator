# V4 告知制度改定 追加要件定義

## 1. 機能要件

| ID | 要件 | 根拠 |
| --- | --- | --- |
| FR-V4-001 | 受付日と告知日を入力する。 | BR-V4-001/002 |
| FR-V4-002 | 再告知フラグにより適用基準日を選択する。 | BR-V4-002 |
| FR-V4-003 | 適用基準日によりOLD/NEW段落を呼び分ける。 | BR-V4-001/003 |
| FR-V4-004 | 適用基準、結果コード、理由、基準日を出力する。 | BR-V4-004 |
| FR-V4-005 | 不正フラグ・回答をデータエラーとする。 | 入力品質 |

## 2. 非機能要件

| ID | 要件 |
| --- | --- |
| NFR-V4-001 | 入力80文字、結果40文字の固定長を維持する。 |
| NFR-V4-002 | 旧判定段落を実行可能な状態で保持する。 |
| NFR-V4-003 | 境界日、再告知、旧契約再査定を試験する。 |

## 3. 対象外

- 商品別COBOLの共通化
- 過去契約データの一括変換
- システム日付だけによる基準選択
