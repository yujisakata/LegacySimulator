# 医療保険・がん保険追加 変更要求書 (V3)

**変更要求ID:** CR-V3-1990-001  
**起票日:** 1990年1月5日  
**販売開始日:** 1990年4月1日  
**関連イベント:** EV-V03-MEDICAL-COPY-001、EV-V03-DOC-001  
**状態:** 承認済み

## 1. 目的

既存の終身保険・特約商品を継続しながら、医療保険とがん保険を新しい主契約商品として追加する。

## 2. 制約

- 販売開始まで3か月とする。
- 既存商品の全面回帰試験期間は確保しない。
- 商品共通モデルの新規設計は行わない。
- 終身保険査定を複製し、商品固有条件を局所的に追加する。
- 原本設計書は改訂せず、商品差分設計書を別冊として発行する。
- 固定長申込120文字、結果80文字を継続する。

## 3. 受入条件

| ID | 条件 |
| :--- | :--- |
| AC-V3-001 | 商品コードMIの医療保険を登録・査定できる。 |
| AC-V3-002 | 商品コードCIのがん保険を登録・査定できる。 |
| AC-V3-003 | 商品別の年齢、保障額、決裁条件を判定できる。 |
| AC-V3-004 | 不備期限、三要件、取下げ、日付点検を複製元と同じ順序で処理する。 |
| AC-V3-005 | 医療系商品へV2特約を付加せず、商品固有領域を空白で受け渡す。 |
| AC-V3-006 | 医療系商品プログラムを個別ロードモジュールとして配布できる。 |
| AC-V3-007 | 新商品中心の代表試験と、既存商品の代表確認結果を記録する。 |

## 4. 成果物方針

要件と設計は差分別冊、ソースは医療系商品の全量版、試験は新商品中心の部分試験とする。V1・V2原本および既存ロードモジュールは変更しない。
