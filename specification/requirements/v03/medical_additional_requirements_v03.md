# 医療保険・がん保険 追加要件定義書 (V3)

**文書ID:** DOC-REQ-V3-001  
**変更要求:** [CR-V3-1990-001](./medical_product_change_request_v03.md)  
**業務規則:** [V3業務ルール差分](../../business_specification/v03/medical_business_rules_delta_v03.md)  
**形式:** V1・V2原本へ対する差分別冊

## 1. 機能要件

| 要件ID | 要件 |
| :--- | :--- |
| FR-V3-001 | 商品別端末からMI・CIの申込を登録する。 |
| FR-V3-002 | 商品コード、年齢、保障額、医的区分、決裁値を点検する。 |
| FR-V3-003 | MIの年齢、日額、一次・二次決裁を判定する。 |
| FR-V3-004 | CIの年齢、診断給付金、一次・二次決裁を判定する。 |
| FR-V3-005 | V1の不備期限、三要件、取下げ、日付点検を継承する。 |
| FR-V3-006 | MI・CIの75～120桁が空白であることを点検する。 |
| FR-V3-007 | V1と同じ主契約結果コード、理由、責任開始日を80文字で出力する。 |
| FR-V3-008 | データエラー後も後続申込を継続し、入出力件数を一致させる。 |

## 2. 非機能要件

| 要件ID | 要件 |
| :--- | :--- |
| NFR-V3-001 | 申込120文字、結果80文字および1～60・69～74桁の意味を継続する。 |
| NFR-V3-002 | 61～68桁は商品別保障額として再定義し、商品コードと組で解釈する。 |
| NFR-V3-003 | MDENTRY・MDASSESSを商品別ロードモジュールとして配布する。 |
| NFR-V3-004 | V1・V2プログラム本体を変更しない。 |
| NFR-V3-005 | 変更行へV3-001のADD/DELコメントと日本語説明を付ける。 |
| NFR-V3-006 | 1990年相当の試験は新商品中心、既存商品は代表確認とする。 |
| NFR-V3-007 | 後世の自動回帰は1990年当時の試験証拠と区別して記録する。 |
| NFR-V3-008 | 原本設計を改訂せず、差分設計書番号と読順を明記する。 |

## 3. 結果コード

V1の01～09を継承する。01承諾、02延期、03謝絶、04不備照会中、05失効、06取下げ、07二次決裁待ち、08入力エラー、09三要件待ちとする。

## 4. 対象外

- MI・CIへのV2特約付加
- 保険料、責任準備金、給付金支払
- 全商品共通ルールエンジン
- 既存商品の全面回帰を1990年のリリース条件とすること
