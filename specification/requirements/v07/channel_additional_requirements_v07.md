# V7 追加要件定義書 — チャネル統合

| ID | 要件 | 受入条件 |
|---|---|---|
| V7-FR-001 | 社員と代理店の権限を分離する | 社員は全件、代理店は同一代理店番号だけ許可する |
| V7-FR-002 | 共通固定長へチャネル既定値を設定する | 社員=`OF`、代理店=`AG`となる |
| V7-FR-003 | 既存COBOL連携形式を維持する | 80文字で受付番号位置を変更しない |
| V7-OPS-001 | 二つのスケジューラの完了を相関する | 受付番号と実行日で受渡しを確認できる |
| V7-ORG-001 | ベンダ引継ぎ範囲と境界を明記する | Spring資産、未解決課題、COBOL責務境界が記録される |
