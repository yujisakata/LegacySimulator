# V8 追加要件定義書 — 外部連携

| ID | 要件 | 受入条件 |
|---|---|---|
| V8-FR-001 | SOAP/ESB/QUEUE接続を共通中間形式へ変換する | 接続先、取引ID、状態、ペイロードを共通に取得できる |
| V8-FR-002 | 応答待ち状態を保持する | 応答前はPENDING_EXTERNALとなる |
| V8-FR-003 | 再送順を維持する | キュー番号の昇順で処理する |
| V8-FR-004 | 重複応答を一度だけ反映する | 接続先＋取引IDが同じ2件目を無視する |
| V8-NFR-001 | COBOL固定長を変更しない | 共通中間形式からV7の80文字へ変換する |
| V8-ORG-001 | 責任分界を明記する | 送信、通信、業務判断、再送承認の担当を識別できる |
