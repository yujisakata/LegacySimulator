# V6 追加要件定義書 — Spring受付

| ID | 要件 | 受入条件 |
|---|---|---|
| V6-FR-001 | 必須項目・年齢・商品を即時点検する | 不正入力を固定長出力前に拒否する |
| V6-FR-002 | COBOL向け80文字レコードを作る | 受付番号を1-10桁、商品を11-12桁、年齢を13-15桁、金額を16-25桁へ出力する |
| V6-FR-003 | 再送でも受付番号を維持する | 同一申込の生成結果で番号が変わらない |
| V6-FR-004 | 2,000万円以上を高額キューへ分離する | 20,000,000以上はHIGH、それ未満はNORMALとなる |
| V6-NFR-001 | 最終査定はCOBOL結果を優先する | Java点検を最終査定として記録しない |
