# 医療保険・がん保険 ビジネスルール差分 (V3)

**文書ID:** DOC-BUS-V3-002  
**変更要求:** [CR-V3-1990-001](../../requirements/v03/medical_product_change_request_v03.md)  
**基準:** V1主契約規則およびV2特約追補

## 1. 共通規則

| ルールID | 規則 |
| :--- | :--- |
| BR-V3-COM-001 | MIとCIは独立した主契約商品として扱う。 |
| BR-V3-COM-002 | V1の不備30日、三要件、取下げ、日付妥当性、レコード単位継続を継承する。 |
| BR-V3-COM-003 | MI・CIではV2特約を付加せず、75～120桁を空白とする。 |
| BR-V3-COM-004 | 正式商品コード以外は入力エラーとする。 |

## 2. 医療保険

| ルールID | 条件 | 判定 |
| :--- | :--- | :--- |
| BR-V3-MI-001 | 年齢0～70歳 | 加入可能 |
| BR-V3-MI-002 | 日額3,000円、5,000円、10,000円 | 保障額条件を満たす |
| BR-V3-MI-003 | 日額3,000円・5,000円かつ標準体 | 一次決裁 |
| BR-V3-MI-004 | 日額10,000円または社医回付 | 二次決裁 |

## 3. がん保険

| ルールID | 条件 | 判定 |
| :--- | :--- | :--- |
| BR-V3-CI-001 | 年齢20～65歳 | 加入可能 |
| BR-V3-CI-002 | 診断給付金100万円、200万円、300万円 | 保障額条件を満たす |
| BR-V3-CI-003 | 100万円・200万円かつ標準体 | 一次決裁 |
| BR-V3-CI-004 | 300万円または社医回付 | 二次決裁 |

年齢条件外は結果08・理由AGE、保障額条件外は結果03・理由AMTとする。二次決裁の論理はV1の承諾・延期・謝絶・未決裁を継承する。

## 4. 適用しないV1・V2条件

- V1の死亡保険金額上限5,000万円
- V1の死亡保険金額2,000万円による決裁境界
- V2のAD・HI特約査定

これらは医療系主契約の商品内容と一致しないため、複製先では実行対象から外す。複製元行はCOBOL内のDELコメントとして保存する。
