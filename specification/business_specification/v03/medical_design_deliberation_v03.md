# 医療系商品 設計検討記録 (V3)

**文書ID:** DOC-BUS-V3-003  
**関連イベント:** EV-V03-MEDICAL-COPY-001、EV-V03-DOC-001

## 1. 採用案

終身保険のオンライン・査定バッチを複製し、MDENTRY・MDASSESSとして商品固有条件を追加する。固定長位置と結果コードを継承し、商品コードでMI・CIを呼び分ける。

## 2. 採用しなかった案

| 案 | 判断理由 |
| :--- | :--- |
| 全商品共通査定プログラムへ再構成 | 3か月の期限内に設計承認と全面回帰を完了できない。 |
| V2 NBASSESSへMI・CI分岐を直接追加 | 既存商品の変更範囲と試験範囲が広がる。 |
| 可変長商品属性ファイルを新設 | 下流と共通ファイルの同時改訂が必要になる。 |

## 3. 文書の読順

V1原本、V2特約追補、V3変更要求、V3商品・ルール差分、V3差分設計書の順に読む。V3差分設計書がMI・CIに対して異なる記述を行う場合、V3差分を優先する。

## 4. 知識状態

- documented: 医療系商品固有ルールと差分設計書番号
- tacit: 複製元と複製先で重複する共通段落、削除理由、読順
- unconfirmed: 将来の共通ルール変更時に修正すべき全商品プログラム
