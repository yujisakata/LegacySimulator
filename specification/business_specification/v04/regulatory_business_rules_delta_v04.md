# V4 告知制度改定 業務ルール差分

## 1. 事業要求

1995年4月1日から新しい告知項目と判定基準を適用する。旧契約の再査定では、当時適用された旧基準を再現できなければならない。

## 2. 追加業務ルール

| ID | ルール |
| --- | --- |
| BR-V4-001 | 通常申込は受付日が1995年4月1日以降なら新基準を適用する。 |
| BR-V4-002 | 再告知フラグがYなら、受付日ではなく告知日で新旧基準を選ぶ。 |
| BR-V4-003 | 旧基準では旧告知回答、新基準では新告知回答を判定する。 |
| BR-V4-004 | 適用した基準と基準日を結果へ記録する。 |
| BR-V4-005 | 新旧どちらの告知回答もYなら謝絶、Nなら承諾とする。 |

## 3. 知識状態

- 形式知: 施行日、新旧回答、再告知フラグ
- 暗黙知: 再告知フラグは一部支社で手入力される
- 未確認: 旧判定を保持すべき最終年度
