# 終身保険特約 (V2) 商品定義書・約款仕様

**文書ID:** DOC-BUS-V2-005  
**商品コード:** PRD-WLI-001（主契約を継承）  
**特約コード:** RID-AD-001 / RID-HI-001  
**発行日:** 1985年2月1日  
**適用開始日:** 1985年7月1日  
**対象Version:** V2  
**管轄部署:** 商品開発部 / 新契約部

本書は[V1終身保険商品定義](../v01/new_business_product_definition_v01.md)へのV2追補である。明示的に変更する事項を除き、V1の主契約定義を継承する。本書に記載する数値は、レガシー進化教材のために設定した架空の会社規則である。

## 1. 追加する特約

### 1.1 災害死亡特約

| 項目 | 定義 |
| :--- | :--- |
| 特約コード | `AD` |
| 給付名称 | 災害死亡保険金 |
| 支払事由 | 所定の不慮の事故を直接の原因として被保険者が死亡した場合 |
| 支払金額 | 申込時に指定した災害死亡特約保険金額 |
| 主契約との関係 | 主契約死亡保険金へ上乗せして支払う |
| 保険期間 | 主契約の保険期間内 |

### 1.2 入院特約

| 項目 | 定義 |
| :--- | :--- |
| 特約コード | `HI` |
| 給付名称 | 入院給付金 |
| 支払事由 | 疾病または傷害の治療を目的として所定の入院をした場合 |
| 支払金額 | 入院給付日額に約款上の支払対象日数を乗じた金額 |
| 主契約との関係 | 主契約死亡保障とは独立した定額給付 |
| 保険期間 | 主契約の保険期間内 |

支払対象日数、免責、請求書類などの支払査定規則は本システムの対象外とし、特約約款原本で管理する。

## 2. 加入・引受制限

| 特約 | 加入年齢 | 保障額 | 主な引受条件 |
| :--- | :--- | :--- | :--- |
| 災害死亡特約 | 満15歳〜満60歳 | 100万円〜2,000万円、100万円単位 | 特約額は主契約死亡保険金額以下。1,000万円超は二次決裁 |
| 入院特約 | 満15歳〜満60歳 | 日額3,000円、5,000円、10,000円 | 標準体は一次決裁、社医回付案件は二次決裁 |

具体的な判定順序と主契約との成立関係は[V2業務ルール差分](./new_business_business_rules_delta_v02.md)を正とする。

## 3. 約款・特約構成

- 主契約: 終身保険普通保険約款（1980年制定版）
- 付加可能特約:
  - 災害死亡特約（1985年制定版）
  - 入院特約（1985年制定版）
- 両特約は同一の終身保険契約へ同時に付加できる。
- 特約だけを単独で契約することはできない。
- 主契約が成立しない場合、特約も成立しない。
- 個別特約が加入条件を満たさない場合、主契約および他方の特約は独立して成立できる。
