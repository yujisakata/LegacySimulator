# 新契約受付～査定結果通知業務 ビジネスルール差分 (V2)

**文書ID:** DOC-BUS-V2-002  
**関連変更要求:** [CR-V2-1985-001](../../requirements/v02/rider_addition_change_request_v02.md)  
**発行日:** 1985年2月15日  
**適用開始日:** 1985年7月1日  
**対象Version:** V2  
**管轄部署:** 商品開発部 / 新契約部 / 査定部

本書は[V1ビジネスルール仕様書](../v01/new_business_business_rules_v01.md)への差分である。V1の年齢、主契約金額、不備期限、三要件、取下げおよび主契約決裁規則は変更しない。

## 1. 共通規則

| ルールID | 規則 |
| :--- | :--- |
| `BR-V2-RDR-001` | 終身保険へ災害死亡特約、入院特約または両方を付加できる。 |
| `BR-V2-RDR-002` | 特約の申込は主契約の申込と同時に行い、特約だけの申込は受け付けない。 |
| `BR-V2-RDR-003` | 正式な特約なしコードは空白とし、特約額をゼロとする。 |
| `BR-V2-CMP-001` | 主契約が承諾以外の場合、申込中のすべての特約を非成立とする。 |
| `BR-V2-CMP-002` | 主契約が承諾の場合、各特約を独立して判定する。一つの特約が謝絶または延期でも、主契約および他方の特約は成立できる。 |

## 2. 災害死亡特約

| ルールID | 条件 | 判定 |
| :--- | :--- | :--- |
| `BR-V2-AD-001` | 契約日時点で満15歳以上60歳以下 | 年齢条件を満たす |
| `BR-V2-AD-002` | 特約保険金額が100万円以上2,000万円以下、100万円単位 | 金額条件を満たす |
| `BR-V2-AD-003` | 特約保険金額が主契約死亡保険金額以下 | 主契約との金額関係を満たす |
| `BR-V2-AD-004` | 特約保険金額が1,000万円以下かつ標準体 | 査定担当者による一次決裁 |
| `BR-V2-AD-005` | 特約保険金額が1,000万円超、または社医回付案件 | 査定医または査定課長による二次決裁 |

年齢または金額条件を満たさない場合、災害死亡特約だけを謝絶とし、主契約と入院特約の判定を継続する。

## 3. 入院特約

| ルールID | 条件 | 判定 |
| :--- | :--- | :--- |
| `BR-V2-HI-001` | 契約日時点で満15歳以上60歳以下 | 年齢条件を満たす |
| `BR-V2-HI-002` | 入院給付日額が3,000円、5,000円または10,000円 | 金額条件を満たす |
| `BR-V2-HI-003` | 標準体 | 査定担当者による一次決裁 |
| `BR-V2-HI-004` | 社医回付案件 | 査定医または査定課長による二次決裁 |

年齢または給付日額条件を満たさない場合、入院特約だけを謝絶とし、主契約と災害死亡特約の判定を継続する。

## 4. 判定順序

1. V1規則で取下げ、入力妥当性、年齢、主契約金額、不備期限、三要件を判定する。
2. V1規則で主契約の決裁結果を確定する。
3. 主契約が承諾でなければ、申込中の特約を非成立とする。
4. 主契約が承諾であれば、災害死亡特約を判定する。
5. 主契約が承諾であれば、入院特約を判定する。
6. 主契約と各特約の結果を独立して通知・証券発行工程へ渡す。

## 5. 特約結果区分

| 区分 | 意味 | 後続処理 |
| :--- | :--- | :--- |
| 承諾 | 特約を付加して成立 | 証券へ特約を記載 |
| 延期 | 現時点では付加せず再評価可能 | 延期通知を作成 |
| 謝絶 | 特約を付加しない | 謝絶理由区分を通知 |
| 決裁待ち | 二次決裁が未完了 | 次回査定へ継続 |
| 非成立 | 主契約が承諾されていない | 特約固有査定を行わない |
| 申込なし | 当該特約を申し込んでいない | 出力対象外 |

## 6. 決裁権限

| 対象 | 一次決裁 | 二次決裁 |
| :--- | :--- | :--- |
| 主契約 | V1の`BR-V1-AUT-001` | V1の`BR-V1-AUT-002` |
| 災害死亡特約 | 1,000万円以下かつ標準体 | 1,000万円超または社医回付 |
| 入院特約 | 標準体 | 社医回付 |

主契約と特約で必要な決裁階層が異なる場合、最も高い決裁階層へ案件を回付する。ただし最終結果は主契約・特約ごとに記録する。

## 7. 変更しないV1規則

- `BR-V1-DEF-001`: 不備照会30日猶予
- `BR-V1-AGE-001`: 主契約加入年齢15〜65歳
- `BR-V1-PRD-001`: 主契約は終身保険
- `BR-V1-AMT-001`: 主契約最高5,000万円
- `BR-V1-AUT-001`, `BR-V1-AUT-002`: 主契約決裁権限
- `BR-V1-RES-001`: 三要件と責任開始日
- `BR-V1-WDR-001`: 成立前取下げ
