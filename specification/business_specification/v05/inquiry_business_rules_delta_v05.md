# V5 照会業務ルール差分

対象Version: V5<br>
想定読者: 業務・検証担当

査定の正本はV4。V5は査定済み結果を表示する。主契約進捗を再判定しない。

| ルール | 内容 |
|---|---|
| BR-V5-001 | 申込番号で1件検索。未存在と結果未連携を区別 |
| BR-V5-002 | 01～09の主契約コードを継承。特約結果と混同しない |
| BR-V5-003 | WL死亡保険金額・MI入院日額・CI診断給付金を商品別に表示 |
| BR-V5-004 | 照会基準日は抽出時点。処理日、責任開始日、制度基準日を置き換えない |
| BR-V5-005 | 新旧制度と適用日はV4から転記。再告知フラグからJavaで再計算しない |
| BR-V5-006 | 同期未完了時に前回正常値を表示する場合がある。基準日と夜間情報の注記を表示 |
| BR-V5-007 | 空白数値はNULL、全桁ゼロは0、ゼロ日付はNULL |

[最終要件](../../requirements/v05/java_inquiry_additional_requirements_v05.md)が受入条件の正本。商品や日付の意味の完全な背景が引継がれたとはしない。
