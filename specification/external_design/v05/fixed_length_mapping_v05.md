# V4→Q5→照会DB 変換表

対象Version: V5<br>
想定読者: 連携・Java・検証担当

位置は1始まり。V4の申込120文字と結果80文字を申込番号で結合する。Q5は新規100文字であり、V4の出力を拡張したものではない。

| Q5位置 | 項目 | V4出典 | DB列・変換 |
|---|---|---|---|
| 1～2 | 形式 | 固定Q5 | DBには保存しない |
| 3～12 | 申込番号 | 申込1～10=結果1～10 | APP_NUMBER、10桁保持 |
| 13～14 | 商品 | 申込69～70 | PRODUCT、WL/MI/CI |
| 15～16 | 主契約結果 | 結果11～12 | STATUS、01～09。結果なしはNULL |
| 17～24 | 保障額 | 申込61～68 | AMOUNT、DECIMAL(8,0)。空白NULL、ゼロ0 |
| 25～32 | 責任開始日 | 結果17～24 | RESPONSIBILITY_DATE |
| 33～40 | 処理日 | 結果25～32 | PROCESS_DATE |
| 41～48 | 受付日 | 申込35～42、結果33～40と照合 | RECEIPT_DATE |
| 49～51 | 制度 | 結果65～67 | RULE_CODE、OLD/NEW/ERR/NULL |
| 52～59 | 制度基準日 | 結果68～75 | APPLIED_DATE |
| 60～67 | 照会基準日 | 抽出時に指定 | AS_OF、必須 |
| 68～70 | 理由 | 結果14～16 | REASON |
| 71 | 決裁区分 | 結果13 | APPROVAL |
| 72～100 | 予約 | 空白29文字 | 非空白は拒否 |

日付の空白8文字または00000000はNULL。それ以外は1900～2099年の実在日をSQL DATEに変換する。負号・桁区切り・全角数値は許容しない。符号なし8桁の保障額のみ。Q5はASCIIであり日本語の文字コード変換は対象外。画面の日本語はUTF-8。

結果なしの場合、結果由来の進捗・責任開始日・処理日・制度・制度基準日・理由・決裁は空白。受付日は申込から保持する。商品と保障額は結果の特約領域から取得しない。

全角/半角、空白/0/NULLを変換の対象ごとに明示した。V4の再告知日選択は変換処理内では再実装しない。根拠: [V4申込](../../../implementation/v04/copybook/NBAPPL.cpy)、[V4結果](../../../implementation/v04/copybook/NBRESULT.cpy)。
